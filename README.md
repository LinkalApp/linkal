# Linkal - Aplicación móvil para dispositivos Android
**Linkal** es una aplicación desarrollada para dispositivos móviles Android diseñada y desarrollada para establecer una conexión entre comercios locales y microinfluencer sin necesidad de intermediarios.

## Objetivo

El objetivo principal de la aplicación móvil Linkal es proporcionar una herramienta móvil, que sirva como solución a la falta de canales directos entre microinfluencers y comercios locales a través de un sistema de matching por interés mutuo, un chat integrado y un sistema de valoraciones que genere confianza entre ambas partes.

Mediante el uso de esta app se pretende facilitar el contacto entre ambas partes, simplificando el proceso de búsqueda de colaboraciones y ofreciendo un entorno centralizado para la gestión de oportunidades.

## Tecnologías principales

### Java
Desarrollado en su mayoria en **Java** para el desarrollo del backend realizado en **IntelliJ** y del frontend gestionado desde **Android Studio**.

### XML
Para desarrollar las interfaces de usuario se usa **XML** desde **Android Studio**.

### PostgreSQL 
Como base de datos se ha obtado por usar una base de datos **PostgreSQL**.
